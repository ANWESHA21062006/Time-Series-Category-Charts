# 📊 Time Series & Category Charts – Internship Project (Week 2)

## 📌 Project Overview
This project focuses on analyzing sales data using time-series and category-based visualizations in Python.

## 🛠️ Tools & Libraries
- Python
- pandas
- matplotlib

## 📈 Visualizations Created
- Monthly Sales Trend (Line Chart)
- Quarterly Sales Trend (Line Chart)
- Category-wise Sales Comparison (Bar Chart)
- Category Contribution Share (Pie Chart)

## 📂 Output Files
- PNG charts for all visualizations
- Text summary report highlighting insights

## 🎯 Key Learnings
- Importance of selecting appropriate chart types
- Time-series aggregation using pandas
- Effective use of labels, legends, and axis formatting
- Exporting visualizations for reporting
